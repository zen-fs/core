# Tests

The shared `fs` suite, its fixture data, and the `zenfs-test` runner are in [`@zenfs/devel`](https://github.com/zen-fs/devel).

- `setup` contains the setups the shared suite is run against
- `backend` contains tests for specific backends
- `common` contains tests that aren't tied to a backend
- `perf` contains the `zbench` performance suites
